# Gold EA Portfolio

MQL5(取引実行)とPython(シグナル判定・ロジック処理)を組み合わせたハイブリッド型自動売買システムの設計例です。

## 概要

XAUUSD(ゴールド)を対象とした自動売買システムを個人で設計・開発しています。
MQL5側でトレード実行を担当し、Python側でAIによるシグナル判定とログ管理を行う構成です。

## アーキテクチャ

- **MQL5**:トレード実行、リスク管理ロジックの実装
- **Python**:シグナル判定、データ処理、ログ管理
- **通信**:WebRequest/Flaskによる MQL5 ⇄ Python 間の連携
- **ログ**:サーバー処理に加え、ローカルCSVへの冗長記録

## 実装している技術要素

- ADX等のテクニカル指標を用いたトレンドフィルタリング
- リスク管理設計(ロット制御、連敗時のサーキットブレーカー)
- バックテスト精度向上のためのコスト(スプレッド等
